# CLAUDE.md — инструкции для AI-ассистента в этом репозитории

## Что это за проект (кратко)
Автогенератор постов для Telegram-канала о **земельном и водном праве РФ** + **бот предварительного согласования** постов владельцем (aiogram). Подробный срез состояния — в **PROGRESS.md**, рабочие команды и рецепты — в **SKILLS.md**.

> **Перед началом работы прочитай PROGRESS.md и SKILLS.md.** Они заменяют перечитывание всего кода.

## Обязательные правила ведения контекста
- **Обновляй `PROGRESS.md` по завершении КАЖДОЙ значимой задачи:** что сделано, что в процессе (с конкретикой «что осталось»), какие решения приняты и почему, на какие грабли не наступать. Это срез, по которому продолжают работу без чтения всего кода.
- **Веди `SKILLS.md`:** дополняй по мере находок — рабочие команды (сборка/деплой/диагностика), устойчивые паттерны, приёмы отладки, нюансы API/окружения, «как правильно сделать типовую операцию здесь».
- **Формат записи:** коротко и по делу, с датой (ГГГГ-ММ-ДД) и конкретикой (`файл:функция`, id сервера, точная команда). Никаких общих фраз — только то, что реально помогает продолжить.

## Специфичные правила проекта (ВАЖНО — соблюдать)
1. **Живая ветка — `claude/claude-md-mm6x6kpv5ry5lx3t-0cgxW`, НЕ `main`.** Весь деплой, данные и история — на ней.
2. **Актуальный код бота — в `bot/app.tar.gz`** (и в локальной рабочей копии, путь — в SKILLS.md), а НЕ в свободных `scripts/*.py` в корне репо (они legacy от эпохи GitHub Actions). Правь локальную копию → пересобери tar → запушь → задеплой (рецепт в SKILLS.md).
3. **Публикует только бот согласования.** Старый автопостинг через GitHub Actions ОТКЛЮЧЁН — не включай обратно, иначе дубли.
4. **Хостинг — Timeweb VPS (РФ), не VibeCode.** Бот под systemd `Restart=always`. VibeCode заброшен (galaxy-app не держит процесс 24/7).
5. **Гео:** сервер в РФ. OpenAI/западные API гео-блокируют РФ — напрямую НЕ использовать. Текст — DeepSeek, картинки/речь — gen-api.ru (рубли); всё из РФ работает.
6. **Голос канала — от лица КОМПАНИИ** («мы / наша команда / наши специалисты»), не блогер-одиночка. Не притягивать услуги за уши, если новость не по нашей теме.
7. **Секреты** (`deploy_secrets.json`, `/opt/app/.env`, токены) в чат/код не коммитить; при утечке — напоминать пользователю о ротации.
