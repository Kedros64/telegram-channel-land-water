## Коротко

## Ключевые решения
- **Timeweb вместо VibeCode:** galaxy-app (Black Hole) не держит процесс 24/7 (нет авто-рестарта) — умирал дважды. Раз весь стек из РФ работает, не-РФ IP не нужен → обычный VPS + systemd `Restart=always`.
- **gen-api.ru вместо OpenAI:** OpenAI отдаёт 403 (гео-блок РФ). gen-api — рублёвый российский агрегатор, из РФ работает и сам проксирует западные модели.
- **Модель рисует подпись, а не overlay:** Nano Banana 2 хорошо рисует кириллицу → Pillow-overlay отключён.
- **Только бот публикует, GitHub Actions выключен:** иначе дубли.
- **Гибрид, а не n8n:** согласование голосом в n8n неудобно; бот — «мозг», публикация — отдельный модуль `channels.py`; n8n — опционально позже как слой fan-out.
- **Шаблонное видео, а не полностью-AI:** для потока 4/день полное AI-видео дорого/медленно и плохо контролирует длинный русский юр-текст; шаблон даёт контроль и ~0–1 ₽/ролик.

## Грабли (чего избегать)
- **Ветка:** не работай в `main` — живая ветка `claude/...`. Данные/деплой там.
- **Код не в корне:** не правь свободные `scripts/*.py` в корне репо (legacy) — источник истины `bot/app.tar.gz` + локальная копия.
- **Timeweb IPv4 не выдаётся автоматически:** вешать `POST /servers/{id}/ips` ТОЛЬКО после статуса `on`, затем **reboot**. Во время `installing` гостевая ОС не сконфигурит IP → порты мертвы.
- **Timeweb анти-фрод (`abuse_prepayment_required`):** быстрый churn серверов/IP поднимает порог предоплаты; удалённые серверы оставляют **платные «плавающие» IP** (`GET /floating-ips`, `resource_id=null`) — обязательно чистить `DELETE`.
- **venv без pip:** на Ubuntu 24.04 `python3 -m venv` без пакета `python3.12-venv` создаёт venv БЕЗ pip/ensurepip → `ModuleNotFoundError`. Бутстрап: `apt update` → `apt install -y python3.12-venv` → venv → `python -m pip install`. На ПЕРВОЙ загрузке без сети apt падает и cloud-init `runcmd` при ребуте не повторяется — доводить бутстрап руками по SSH.
- **Промпт-дрейф DeepSeek:** формат блока ВИЗУАЛ модель иногда меняет (`Фото:` вместо `Prompt (EN):`) — парсер держать терпимым (сделано).
- **Кавычки на обложке:** модель любит `«»` вокруг подписи — держать санитайзер + инструкцию «render caption with NO quotation marks».
- **gen-api `/user` врёт:** эндпоинт проверки баланса даёт «неверный ключ» даже на рабочем ключе — проверять ключ реальной мелкой генерацией.
- **Секреты в чат:** токены присылали в чат — не логировать, напоминать о ротации.
